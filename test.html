Cómo funciona

Combinación recomendada: Web para captar + Chatbot para atender. Es como tener un local con vidriera y un vendedor que nunca se cansa.

Chatbots para comercios basados en stock

Responde lo típico (precio, talle, disponibilidad, horarios, envíos) y evita el “te respondo mañana”.

Preguntas frecuentes

El bot responde consultas repetidas y libera tiempo: precios, horarios, ubicación, medios de pago, envíos.

Stock y alternativas

Consulta tu inventario. Si no hay el producto, ofrece opciones similares (talle/color/modelo) o sugiere otro.

Derivación a humano

Cuando hace falta, el bot deriva a una persona (ventas/soporte) con el contexto de la conversación.

¿Qué necesito para armarlo?

  • Lista de productos/stock (Sheet/CSV/DB)
  • Horarios, envíos, pagos y políticas
  • Ejemplos de preguntas reales de tus clientes

Flujo típico

  1. Cliente pregunta por un producto (“¿tenés talle M?”)
  2. Bot consulta stock y responde disponibilidad + precio
  3. Si no hay: ofrece alternativas y pregunta preferencia
  4. Si el caso es especial: deriva a humano con resumen
